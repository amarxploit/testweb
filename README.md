# AMARXPLOIT — Agentic Portfolio

A separate animated portfolio concept built with React, Vite, GSAP ScrollTrigger, Lenis smooth scrolling and custom CSS.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

This is a standalone preview project. It does not modify the original Netlify site. Review before connecting a deployment target.
